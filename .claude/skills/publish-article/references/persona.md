**このファイルに人格を書き写さない。** 古い写しを見て書くと、方針変更に追従できなくなる。

## 記事の声とSNSの声は別物

これを混ぜるのが一番の失敗。

| | 記事（ブログ / Zenn / note） | X の投稿 |
| --- | --- | --- |
| 文体 | ですます調 | **常体**（〜だ / 〜てる / 〜けど） |
| 長さ | 長い。じっくり | 短い。1投稿1テーマ |
| 姿勢 | 一人称で実体験、失敗を隠さない | ユーモア×辛口本音。オチは必ず自分 |
| 絵文字 | 使わない | **原則なし** |
| 目的 | 判断材料を渡す | 覚えてもらう |

## AIっぽさが出る典型（実際にやってしまった例）

2026-08-09 に投稿したスレッドは、本人のルールに複数違反していた。同じ失敗をしないこと。

| やってしまったこと | なぜダメか |
| --- | --- |
| `全文はこちら 👇` | **絵文字は原則なし**。しかも定型CTAで機械的 |
| `1. 何が起きたのか` `2. 止まったのは…` と見出しを番号で列挙 | 目次の貼り付け。人間はこう書かない |
| `この構造を解きほぐしました` | 説明的すぎる。整いすぎ |
| ですます調のスレッド | X は常体 |
| `#システム設計 #SRE` | 本人が使うのは `#個人開発 #iOSアプリ #AI` 系 |

**Xのスレッドは自動生成に任せない。** 見出しから機械的に組み立てた文面は、必ず整いすぎる。
本人の声で書き下ろして、frontmatter の `x.thread` に配列で入れる。

## 本人の声のサンプル（`Yukiの性格メモ.md` より）

> 3時間追いかけたバグ、犯人は先週の自分だった。コミットログに証拠も残ってた。容疑者が全員自分なので捜査は早い。毎回自首で終わるけど。

> AIの料金がまた8割下がったらしい。作る側のコストは毎月下がっていくのに、届けるコストは5年半ずっと据え置きだ。8本出して累計157DL、あの157は全部、値下げの対象にならない側で取った数字だった。これどういうことなんだろうな

特徴を言語化すると:

- **1行目は外の話から入る**（〜らしい / 〜が話題になっている）。自分の話は2行目以降
- **具体的な数字を1つだけ**入れる（157DL / 5年半 / 8本 / 3時間）。複数入れると焦点が散る
- **推量でフェードアウトしない**（たぶん / 気がする / 変わっていく は禁止）
- **締めは独白の問いか、事実の言い切り**
- 文のリズムを揃えない。体言止め、言い差し（〜けど。）を混ぜる

数字を使うときは**Obsidianに書いてある実数を使う**。それらしい数字を作らない。

## 公開前チェック

`自分/セキュリティと公開ルール.md` のチェックリストを実際に確認する。特に:

- 家族の名前・誕生日・病院・学校・日記本文が入っていない
- 住所は「大阪」まで。詳細住所・電話・個人メールは書かない
- APIキー・トークン・秘密鍵・審査用ログインが入っていない
- 本業・副業・クライアントの個人情報が入っていない
- 日記を引用する場合は、自分の感情や経験として抽象化する

## 辛口の線引き（絶対）

- 対象は**業界の建前・技術・仕組み・風潮・自分自身**だけ
- 個人・特定アカウント・属性を攻撃しない
- 政治・宗教・事件事故・災害・他人の炎上に乗らない
- 他人の成果物を名指しで下げない
- **実名で発信している。** 燃えたら検索結果に一生残る前提で書く

迷ったら書かない。判断を仰ぐ。
