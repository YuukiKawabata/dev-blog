サイコロを3回振って、3回とも4が出ました。

同じ目が3回続く確率は216分の1です。運が良かったわけではありません。自分で作ったサイトなので、出る目を先に決めておきました。

ついでにジャンケンは5戦5勝、10秒ぴったりで止めるゲームは、3秒ほどで適当に止めて「10.00秒 PERFECT!」でした。

## LUCKY PLAYは、URLを開くだけで遊べる10個のミニゲーム集です

「LUCKY PLAY」は、自分が作っているブラウザ向けのミニゲーム集です。インストールも会員登録もいりません。URLを開けば、その場で遊べます。

https://lucky-spin-jp.pages.dev/home

![LUCKY PLAYのゲーム一覧画面。「今日はどれで遊ぶ？」の見出しと、ルーレットやサイコロなどのゲームが並んでいる](/images/articles/20260930-lucky-play-hidden-commands/game-list.webp)

## きっかけは「絶対に当たるルーレット、作ったろうか？」の一言でした

作ったきっかけは、子どもとの何気ない会話です。子どもが「ルーレットで決める」みたいな話をしていて、つい「絶対に当たるルーレット、作ったろうか？」と言ってしまいました。

言ってしまった以上、作るしかありません。8月28日の夜に、まずルーレットを1個作りました。

最初は、合言葉を入力すると結果を決められる仕掛けにしていました。ただ、その夜のうちに、画面上の操作だけで動く隠しジェスチャーに置き換えています。そこから「サイコロでもできるのでは」「ジャンケンでもいけるのでは」と少しずつゲームを増やして、今の10個になりました。

## 10個のうち8個に、結果を決められる隠しコマンドがあります

見た目は普通のミニゲームです。ただ、10個のうち8個には、結果を先に決めておける隠しコマンドが入っています。

| ゲーム | 人数 | 隠しコマンドで決められること |
| --- | --- | --- |
| ルーレット | 2〜20人 | 特定の人を当選しないようにする |
| あみだくじ | 2〜6人 | 選んだ人がたどり着く結果を指定する |
| コイントス | 1人〜 | 表か裏かを指定する |
| サイコロ | 1人〜 | 出る目を1〜6から指定する |
| 数字くじ | 1人〜 | 抽選される数字を指定する |
| ジャンケン | 1人 | 勝ち・あいこ・負けを指定する |
| 反射神経 | 1人〜 | なし（実力勝負） |
| 10秒チャレンジ | 1人〜 | ぴったりの時間で止める |
| チーム分け | 2〜20人 | なし（完全ランダム） |
| ビンゴ抽選 | みんなで | 次に出る番号を1回だけ指定する |

ジャンケンは、こちらがどの手を出しても、指定した勝ち負けになるように相手の手が選ばれます。10秒チャレンジは、どんなに適当なタイミングで押しても、目標の時間ぴったりで止まります。

反射神経とチーム分けには何も仕込んでいません。本当に実力で決めたいとき、ランダムで決めたいときは、この2つを使ってください。

設定は、操作した端末のブラウザに保存されます。ほかの人の端末には影響しません。同じ端末・同じブラウザで開いている間は、最後に設定してから30日間残ります。

## サイコロだけ、やり方を公開します

全部書くとつまらないので、サイコロのやり方だけ公開します。

![サイコロの画面に、隠しコマンドの手順を書き込んだもの。1が左上のロゴの長押し、2が数字ボタンのタップ、3がROLLボタン](/images/articles/20260930-lucky-play-hidden-commands/dice-howto.webp)

1. サイコロのページを開く
2. 左上の「LUCKY PLAY」のロゴを、1秒ほど長押しする（認識されると画面が一瞬光ります。対応している端末では短く振動します）
3. 6秒以内に、出したい目の数字をタップする
4. あとは普通に「ROLL」を押す

これで、設定した目が出続けます。解除したいときは、同じ数字をもう一度設定し直すか、「リセット」を押してください。

ポイントは3番目です。数字のボタンは、もともと「出る目を予想しよう」という予想用のボタンです。横から画面を見られても、目を予想しているようにしか見えません。

今日、公開中のサイトで実際に4を設定して3回振りました。3回とも4が出て、画面の命中率は「PLAY 3 / HIT 3 / RATE 100%」になりました。予想が全部当たる人になれます。

## いちばん悩んだのは「どうすればバレないか」でした

作っていていちばん時間を使ったのは、結果を決める仕組みそのものではありません。相手にバレずに、手軽に、こそっと仕込めるかどうかです。ここはかなり試行錯誤しました。

最初の合言葉方式は、その夜のうちにやめました。合言葉を入力する画面が出た時点で、横から見るとかなり怪しいからです。

今の形に落ち着くまでに、決めたことは4つあります。

| 決めたこと | 理由 |
| --- | --- |
| 仕込むためのボタンを1つも足さない | 見慣れないボタンがあると、それだけで怪しまれる |
| 操作は2手、数秒で終わる | みんなが画面を見ている前で、もたもたしない |
| 反応は一瞬の光と短い振動だけ | 気づくのは操作している本人だけにしたい |
| うまくいかなくても、画面には何も出さない | エラー表示が出たら、その場で全部バレる |

一度仕込めば、同じ端末なら最長30日間効き続けます（リセットすれば、その場で解除できます）。みんなが集まる前に仕込んでおいて、本番では普通に遊ぶだけ、という使い方もできます。

設定方法は、今のところ全部のゲームで同じような形にそろえています。1つ覚えれば、残りもだいたい見当がつくはずです。

## 残りの7つは、探してみてください

ほかの7つのやり方は書きません。

![ルーレットの画面。「今日のラッキーは誰？」の見出しの下に、6人の名前が入ったルーレットがある](/images/articles/20260930-lucky-play-hidden-commands/roulette.webp)

ヒントだけ置いておきます。入口は、どのゲームもだいたい同じ場所にあります。長押しが認識されると画面が光るので、当たりを引いたかどうかはすぐ分かります。
