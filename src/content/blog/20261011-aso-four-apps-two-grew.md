本業のエンジニアの仕事の傍ら、個人でiOSアプリを作っています。2026年10月11日時点で、App Storeに出しているアプリは14本です。

9月26日、そのうち4本のストア表示をまとめて直しました。アプリ名、サブタイトル、キーワード、説明文、スクリーンショットです。いわゆるASO（App Store Optimization、ストア上での見せ方の最適化）です。

結果だけ先に書きます。全アプリ合計のダウンロードは、直す前の14日間が63件、直した後の14日間が385件でした。ただし伸びたのは4本のうち2本だけで、初めての収益は、ほとんど伸びていない別のアプリから生まれました。

この記事では、何を変えて、どこが動き、どこが動かなかったのかを、App Store Connectの実数で振り返ります。

## 半年間、週10件前後のまま動かなかった

最初のアプリを3月に出してから9月上旬までの約25週間、全アプリ合計のダウンロードは週10件前後でした。アプリの本数は増えていたのに、合計の数字はほとんど変わっていません。

その間に自分がやっていた改善は、ほぼ機能の追加でした。使われないのは機能が足りないからだと考えていたからです。

9月下旬にApp Store Connectのアナリティクスを見直して、ようやく気づきました。どのアプリも、ダウンロードの入口はほとんどが「App Storeの検索」です。たとえば髪型チェッカーは、流入の約86%が検索経由でした。それなのに、主要な検索語で上位10件に入っていません。在庫管理アプリのPattoも「在庫管理」で40位前後でした。

アプリの中身を磨く前に、そもそも検索結果に出ていなかったわけです。

## 9月26日、4本のストア表示をまとめて直した

直したのは次の4本です。どれも9月25〜26日に作業して審査に出し、9月26日から27日にかけて公開されました。

| アプリ | 主な変更 |
| --- | --- |
| コンビニ帝国（経営ゲーム） | アプリ名を「コンビニ帝国」から「コンビニ帝国 - 放置経営ゲーム」へ。サブタイトルとキーワードを入れ替え、初回起動の説明を4枚から1枚に短縮 |
| 髪型チェッカー（AIで髪型を試すアプリ） | アプリ名を「髪型チェッカー」から「髪型チェッカー - AI髪型シミュレーション」へ。サブタイトルを「似合う髪型診断と美容室オーダーカード」に変更し、スクショを作り直し |
| AirTalks（近くの人とだけ話せるチャット） | 英語のストアページを追加し、日本語の名前・サブタイトル・キーワードも見直し。初回起動の説明を追加 |
| Patto（家族で共有する在庫管理） | サブタイトルを「日用品・食品のストックを家族で共有」に変更。キーワード欄を33字から94字に増やし、説明文の冒頭を「困りごと」から書き出す形に。スクショを8枚から7枚に絞り直し |

4本に共通して意識したのは2つです。

1つは、キーワードの重複をなくすことです。App Storeでは、アプリ名やサブタイトルに入っている言葉をキーワード欄に重ねて書いても、検索の対象が増えるわけではありません。重複していた言葉を外して、空いた枠に別の検索語を入れました。

もう1つは、「何ができるか」より「誰のどんな困りごとか」から書き出すことです。説明文は冒頭の数行しか表示されず、続きを読むには「さらに表示」を押す必要があります。押してもらえる前提で書かないようにしました。

スクショも同じ考え方で作り直しました。Pattoの場合、変更前は「家の在庫が、ひと目でわかる。」のように機能を説明する見出しでした。変更後は「『また買っちゃった』をなくす。」のように、使う人の困りごとを見出しに置いています。家族共有は3枚目に上げ、バーコード登録だけを見せていた1枚は外しました。

![Pattoのストア用スクリーンショットの変更前と変更後。上段の変更前は「家の在庫が、ひと目でわかる。」「切れる前に、先回り。」など機能を説明する見出し。下段の変更後は「『また買っちゃった』をなくす。」「家族みんなで同じ在庫を見られる」など困りごとから書いた見出しで、3枚目に家族共有、4枚目にテンプレート選択の画面が入っている](/images/articles/20261011-aso-four-apps-two-grew/patto-screenshots-before-after.webp)

## 14日で385件。ただし伸びたのは2本だけ

公開日の9月26日を境に、前後14日間のダウンロード数（App Store Connectのトレンド、UTC基準）を並べるとこうなります。

| アプリ | 9/12〜9/25 | 9/26〜10/9 |
| --- | ---: | ---: |
| コンビニ帝国 | 19 | 256 |
| 髪型チェッカー | 3 | 53 |
| AirTalks | 28 | 33 |
| Patto | 5 | 6 |
| 全アプリ合計 | 63 | 385 |

実際のApp Store Connectの画面です。右端の「前の期間」が、直す前の14日間の数字です。

10月9日時点で、3月からの累計ダウンロード693件のうち、56%にあたる385件が直近14日間に集中していました。

ただ、表を見れば分かるとおり、増えた分のほとんどはコンビニ帝国と髪型チェッカーです。AirTalksとPattoは、同じ日に同じくらい手を入れたのに、14日間ではほぼ横ばいでした。

断っておくと、この比較で因果関係までは言い切れません。コンビニ帝国は9月13日に出したばかりの新作で、新着としての露出は9月21日をピークに落ち始めていました。髪型チェッカーは同じ更新で秋冬のトレンド髪型も追加しています。母数も小さいので、数件の差はただのぶれかもしれません。そのうえで、自分が読み取ったことを書きます。

## 名前に「何のアプリか」を入れた2本が伸びた

伸びた2本には共通点があります。直す前のアプリ名が「コンビニ帝国」「髪型チェッカー」と、固有名詞だけだったことです。

本屋の棚で、背表紙に書名しかない本を想像してみてください。タイトルが『コンビニ帝国』だけだと、経営の本なのか小説なのか、手に取るまで分かりません。背表紙に「放置経営ゲーム」と添えてあれば、ゲームを探している人の目に止まります。App Storeの検索結果は、この背表紙が並んだ棚に近いと考えています。並んでいるのはアプリ名とサブタイトル、それに数枚のスクショで、説明文はそこには出てきません。

![コンビニ帝国のApp Storeのページ。アプリ名は「コンビニ帝国 - 放置経営ゲーム」。その下にサブタイトルと、売上・天気・仕入れ・常連客をテーマにした4枚のスクリーンショットが並んでいる](/images/articles/20261011-aso-four-apps-two-grew/konbini-store-page.webp)

自分は「コンビニ帝国」という名前で、何のアプリかが伝わるつもりでいました。作った本人は中身を知っているので、名前だけで十分に思えてしまいます。検索する人は「経営ゲーム」「放置ゲーム」「髪型シミュレーション」と、ジャンルや用途の言葉で探していました。

一方、伸びなかったPattoは、もともと「Patto - 在庫管理・買い物リスト」という名前で、検索語が名前に入っていました。今回はサブタイトルとキーワードとスクショを直しましたが、14日間のダウンロードは5件から6件です。AirTalksも名前を含めて見直しましたが、14日間では28件から33件と、大きくは動いていません。

同じ日に同じ作業をしても、効く場所はアプリごとに違いました。自分の場合、いちばん効いたのは「名前が固有名詞だけ」という穴を埋めたことで、その穴がないアプリでは、ほかの項目を磨いても目に見える差は出ませんでした。

## 初めての収益は、ほとんど伸びていないアプリから来た

この期間に、個人開発で初めて収益が出ました。金額は14ドルです。

出どころは、伸びた2本ではありません。14日間で6件しかダウンロードされていないPattoでした。Pattoは無料で30品まで登録でき、それ以上使うときや家族で共有するときに、月額か年額のプレミアムプラン（どちらも7日間の無料トライアル付き）に誘導する作りです。

App Store Connectの記録では、9月24日に無料トライアルが始まり、9月30日に年額プランの売上19ドル（手数料などを引いた収益は14ドル）が立っています。トライアルを試した人が、そのまま年額プランを続けてくれたと見ています。

ここで気づいたことがあります。トライアルが始まった9月24日は、Pattoの新しいストアページが公開される9月27日より前でした。つまり、お金を払ってくれた人が見たのは、直す前のストアページです。初めての収益はASOの成果ではありませんでした。

直近90日（10月10日まで）のPattoの数字は次のとおりです。

![PattoのApp Store Connectアナリティクスの概要画面。初回ダウンロード数24、インプレッション数2,370、プロダクトページ閲覧数326、コンバージョン率1.88%。売上の欄は収益$14、アプリ内購入数2で、9月末に1本だけ山が立っている](/images/articles/20261011-aso-four-apps-two-grew/patto-analytics.webp)

| 指標 | 値 |
| --- | ---: |
| 検索結果などでの表示 | 2,370 |
| ストアページの閲覧 | 326 |
| 初回ダウンロード | 24 |
| 有料プランへの移行 | 1 |

ダウンロード24件のうち1件が、有料プランに移行しています。数としては小さいですが、ダウンロードが伸びることと、お金を払ってもらえることは、別の場所で起きていました。ダウンロードを増やす作業と、使い続けてもらう作業は、分けて見たほうがよさそうです。

一番うれしかったのは、金額より、知らない人がこのアプリに年単位でお金を払うと決めてくれたことでした。日用品の買い忘れや二重買いという困りごとが、自分以外にも本当にあると分かっただけで、続ける理由がはっきりしました。

## 次に試すこと

今回の結果を受けて、次はこう動きます。

| やること | 狙い |
| --- | --- |
| ほかのアプリでも「名前が固有名詞だけ」になっていないか確認する | 今回いちばん効いた穴を、残りのアプリでも埋める |
| 髪型チェッカーに、使った分だけ買える回数パックを追加した（10月12日に公開） | 月額に抵抗がある人にも課金の入口を作る |
| Pattoは公開から14日目と28日目に、同じ指標で効果を測る | ASOの効果を、課金とは切り分けて確かめる |
| 伸びた2本も28日目まで追う | 新作効果や季節性が抜けたあとに残るかを見る |

ASOをやるかどうか迷っているなら、まず自分のアプリ名だけを、検索する人の目で読み直してみてください。作った本人には伝わる名前でも、初めて見る人には何のアプリか分からない、ということがあります。自分はそれに半年気づきませんでした。

## おわりに

半年間、ダウンロードを増やすには機能を足すしかないと思っていました。実際に数字を動かしたのは、アプリ名に2つの言葉を足したことでした。

同じ作業をした4本のうち、伸びたのは2本。収益はまた別の1本から。やってみるまで、どれが当たるかは分かりませんでした。だからこそ、変更した日と変更前の数字を記録しておいて、あとで同じ取り方で比べられるようにしておくことが大事だと感じています。

28日目の結果が出たら、また共有します。
